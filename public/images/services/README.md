# public/images/services/

Bilder für den Abschnitt „Woran wir täglich arbeiten" auf der Startseite.
Empfohlen: 1600 × 1100 px, JPG oder WebP, unter 300 KB.

| Datei | Motiv |
|---|---|
| `webdesign.jpg` | Entwurf/Wireframe einer Website (z. B. Tablet mit Skizze) |
| `entwicklung.jpg` | Code, Editor, Technik |
| `shop.jpg` | Onlineshop auf Notebook oder Bildschirm |
| `sichtbarkeit.jpg` | Auswertung, Zahlen, Dashboards |

Solange eine Datei fehlt, zeigt die Karte einen markierten Platzhalter
statt eines kaputten Bildes.
